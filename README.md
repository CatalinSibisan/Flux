# Flux - Music Application

Flux is a Python-based application that allows you to listen to and download MP3 files.
The app uses the **Tkinter** and **CustomTkinter** libraries for the graphical interface, and **pygame**, **time**, and **os** libraries for audio playback and file management.
With Flux, you can select a folder to organize your music, play your favorite tracks, pause, repeat, and control the volume.
You can see the design of the app here: https://www.figma.com/design/WXiSfvZ6xGBjiBGBOk0vIj/FluxApp?node-id=0-1&t=bEETEGkMii7bXgAP-1

## Description

Flux is a simple and efficient application for listening to and downloading MP3 files. Users can select a folder to store their favorite music, and the application will quickly load and play the audio files. Besides playback, the app offers features like pause, skip, repeat, and volume control.

Flux is ideal for those who want to organize and enjoy their music in a simple and user-friendly way without relying on complex applications.

---

## Technologies Used

- **Python** 3.x
- **Tkinter** - for the graphical interface
- **CustomTkinter** - for interface customization
- **pygame** - for audio playback
- **os** - for file and folder management
- **time** - for handling timing and playback events

---

## Features

Flux offers the following features:

- **Select a custom folder**: You can choose a folder where your MP3 music files are stored, and the app will load and display those files.
- **Audio playback**: Play your favorite tracks directly from the app.
- **Pause and resume**: Pause the song and resume it later.
- **Skip and rewind**: Skip forward or backward in the song to listen to specific parts.
- **Repeat song**: Set the song to repeat for continuous playback.
- **Volume control**: Adjust the volume to your desired level.

---



## Usage

After running the application, follow these steps to use it:

  1. Select a folder - Choose the folder where your MP3 files are stored, and the app will load them.
  2. Play a song - Click on any of the available tracks to play it.
  3. Control playback - Use the pause, skip, and repeat buttons to control the song's playback.
  4. Adjust volume - Use the volume control to adjust the song's volume.
